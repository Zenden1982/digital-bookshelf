# Живая цифровая библиотека

## Краткое описание
Веб‑приложение «Живая цифровая библиотека» — личная цифровая полка с интерактивными обложками, встроенной читалкой, семантическим поиском и локальной нейросетью для тегов, конспектов, рекомендаций и генерации обложек.

## Цели и задачи
**Цель:** создать автономную систему ведения личной библиотеки с умным поиском «по смыслу», аналитикой чтения и удобной визуальной полкой.

**Задачи:**
*   Хранение книг и метаданных.
*   Визуальная полка со статусами.
*   Читалка с заметками.
*   Локальный AI для конспектов/тегов/перевода.
*   Векторный поиск.
*   Аналитический дашборд.
*   Импорт/экспорт.
*   Приватность и офлайн‑режим.

## Ключевая идея: Живая полка
*   **Главный экран:** интерактивные ряды книг: «Читаю», «В планах», «Прочитано», «Отложено», «Избранное».
*   **Карточка книги:** обложка, прогресс, рейтинг, теги, быстрые действия («Продолжить», «Заметки», «Похожие», «Изменить статус»).
*   **Взаимодействие:** Перетаскивание между рядами меняет статус; быстрый импорт файлом или по ISBN; генерация обложек при их отсутствии.

## Функциональные возможности
*   **Добавление книг:** по ISBN/названию из публичных каталогов с автозаполнением метаданных; ручное добавление файлов ePub/FB2/PDF.
*   **Генерация обложек:** локальная модель создаёт обложки по названию/жанру/описанию, если нет в каталоге; возможна загрузка своей.
*   **Встроенная читалка:** поддержка ePub/FB2, базовый PDF, синхронизация прогресса, закладки, выделение цитат, заметки, темы день/ночь/sepia, настройка шрифта и интерлиньяжа.
*   **AI‑ассистент в читалке:** объяснение сложных мест, перевод фрагментов, краткие конспекты глав и всей книги, создание карточек знаний (персонажи, термины, сюжет).
*   **Семантический поиск:** поиск по смыслу по названиям, описаниям, заметкам и цитатам на основе векторных представлений.
*   **Рекомендации:** выдача похожих книг с пояснением причины (темы, настроение, стиль), «мини‑микс» для быстрого старта чтения.
*   **Интеллект‑карта чтения:** граф связей «книги—темы—теги—авторы—цитаты», кластеры по жанрам и эпохам, фильтры и подсветка «белых пятен».
*   **Аналитика «Читательское ДНК»:** любимые жанры/авторы/языки, скорость чтения, длина книг, динамика по месяцам, цели года, челленджи и достижения.
*   **Социальные функции:** публичные полки/подборки по ссылке, «комнаты» для совместного чтения 2^5 человек с общими заметками и обсуждениями.
*   **Импорт/экспорт:** импорт из Goodreads/CSV/Calibre; экспорт заметок в Markdown (например, для Obsidian).
*   **Управление файлами:** drag‑and‑drop, сканирование ISBN, дедупликация по хешу, нормализация метаданных, превью.
*   **OCR для PDF‑сканов:** распознавание текста для цитат, поиска и конспектов.
*   **Приватность и офлайн:** локальная обработка AI без внешних отправок, гибкая приватность для полок и заметок, офлайн‑доступ с последующей синхронизацией.
*   **Мотивация:** ежедневные/недельные цели, ритуалы чтения, дайджесты «что нового и что дальше читать», лента событий.

## Архитектура
*   **База данных:** PostgreSQL, хранение пользователей, книг, авторов, заметок, цитат, прогресса, тегов, связей и логов задач.
*   **Векторный слой:** pgvector для embeddings книг, описаний, заметок и запросов; индекс для быстрого семантического поиска.
*   **Локальная нейросеть:** развернутая на ПК/сервере LLM и модель эмбеддингов; задачи — генерация тегов/конспектов, перевод, объяснения, рекомендации, создание обложек (через локальные диффузионные модели).
*   **Backend:** Java + Spring Boot, REST API, модули пользователей и авторизации, библиотека и статусы чтения, заметки/цитаты, интеграции с каталогами, очередь фоновых задач, модуль семантического поиска, аудит и метрики.
*   **Безопасность:** Spring Security, сессионная аутентификация, CSRF‑защита, ролевая модель (user/admin), настройки приватности на уровне объектов.
*   **Frontend:** интерфейс полки, читалка, интеллект‑карта (D3), аналитический дашборд; варианты реализации — React SPA или шаблоны на сервере (Thymeleaf + htmx).
*   **Развертывание:** Docker Compose для backend, БД, фронтенда, локальной LLM и задач; логи, метрики и бэкапы.

## Модули backend
*   **Пользователи и сессии:** регистрация/логин, восстановление, профили, настройки приватности и языка, API‑ключи локальных сервисов.
*   **Каталог и импорт:** поиск по ISBN/названию/автору, парсинг метаданных, сохранение обложек, fallback на генерацию.
*   **Библиотека:** книги, статусы, списки и подборки, прогресс чтения, даты старт/финиш, рейтинг, теги и жанры.
*   **Заметки и цитаты:** CRUD, теги, экспорт, связывание с главами, версиями и позициями в тексте.
*   **Читалка:** позиции чтения, маркеры, форматирование, загрузка/хранение файлов, предпросмотр.
*   **Семантический поиск:** создание embeddings, индексация, запросы, пересортировка результатов, объяснения рекомендаций.
*   **AI‑функции:** теги, конспекты, резюме глав, карточки знаний, перевод/объяснения, генерация обложек, контроль качества и ретраи.
*   **Интеллект‑карта:** расчёт узлов и связей, сериализация графа, API для визуализации.
*   **Аналитика:** агрегаты по чтению, временные ряды, цели/челленджи, дайджесты.
*   **Импорт/экспорт:** парсеры (Goodreads/CSV/Calibre), экспорт Markdown/JSON, валидация и дедупликация.
*   **Админ:** мониторинг, очереди, бэкапы, миграции схемы, квоты диска, аудит действий.

## Очереди и фоновые задачи
*   **Постановка задач:** генерация embeddings, конспектов, обложек, OCR, переиндексации, рассылки дайджестов.
*   **Планировщик:** расписание ночных задач, дедлайны, повторные попытки при ошибках, контроль нагрузки CPU/GPU.
*   **Идempotентность и трейсинг:** ключи задач, логи, метрики времени/памяти, алерты при деградации.

## Данные и схема БД (укрупнённо)
*   Users, Profiles, Sessions.
*   Books, Authors, Series, BookFiles, Covers.
*   Shelves/Lists, ShelfItems, ReadingStatus, ReadingProgress.
*   Notes, Highlights, Tags, BookTags, QuoteFragments.
*   Embeddings (book, note, query), Recommendations, Similarities.
*   Tasks, TaskLogs, Metrics, Backups, Migrations.

## Пользовательские сценарии
1.  **Добавление книги по ISBN:** введён код — получены метаданные и обложка, книга на полке «В планах».
2.  **Добавление файла:** перетянут ePub — создана карточка, метаданные распознаны, обложка сгенерирована локально.
3.  **Продолжить чтение:** клик по «Продолжить» открывает читалку, синхронизируется позиция, заметки доступны в боковой панели.
4.  **Цитата с объяснением:** выделен абзац — создана заметка, ассистент даёт объяснение и перевод.
5.  **Поиск по смыслу:** запрос «мистический триллер про осеннее озеро» — найдены книги и собственные заметки схожего настроения.
6.  **Рекомендация:** на карточке «Похожие» — объяснение «похоже по теме взросления и тону повествования», добавление в подборку.
7.  **Интеллект‑карта:** фильтр по жанру — видны кластеры, подсказка закрыть пробел «современная поэзия», переход к рекомендованной книге.
8.  **Аналитика:** цель «12 книг в год», видно отставание, подсказка «короткие нон‑фикшн на 150^200 стр».

## Нефункциональные требования
*   **Производительность:** lazy‑loading полки и обложек, индексы БД, кеш превью, асинхронные AI‑задачи; целевой TTFB < 200 мс для основных эндпоинтов.
*   **Надёжность:** атомарность операций импорта, транзакции при изменении статусов и прогресса, авто‑повторы фоновых задач.
*   **Масштабируемость:** горизонтальное масштабирование backend, вынос локальной LLM в отдельный сервис, шардинг файлового хранилища.
*   **Безопасность:** шифрование конфиденциальных полей, контроль доступа по объектам, защита от XSS/CSRF/SQL‑инъекций, аудит.
*   **Доступность:** управление с клавиатуры, контрастные темы, адаптация под мобильные устройства, ARIA‑атрибуты.

## Технологический стек
*   **Backend:** Java 17+, Spring Boot, Spring Data JPA, Spring Security, REST.
*   **База данных:** PostgreSQL, расширение pgvector.
*   **Локальный AI:** LLM и модель эмбеддингов на ПК/сервере; диффузионная модель для обложек; поддержка квантованных моделей.
*   **Frontend:** React или Thymeleaf + htmx; D3.js для карты связей; компонент читалки ePub/FB2.
*   **Развертывание:** Docker Compose; логи и метрики; планировщик фоновых задач.

## Критерии готовности
*   Полка с рядами и интерактивными карточками, операции статусов и прогресса.
*   Импорт книг из каталога и из файлов, генерация обложек при отсутствии.
*   Читалка с заметками и цитатами; ассистент с объяснениями, переводом и конспектами.
*   Семантический поиск и «похожие книги» с объяснениями.
*   Интеллект‑карта чтения и аналитический дашборд.
*   Импорт/экспорт, приватность, офлайн‑режим.
*   Мониторинг, очереди задач, бэкапы.

## Перспективы развития
*   Мобильное приложение и синхронизация.
*   Распознавание персонажей и сюжетных линий; граф персонажей.
*   Локальный TTS для озвучки фрагментов.
*   Дообучение эмбеддингов на личных заметках для повышения качества рекомендаций.
*   Гибридный поиск: full‑text + embeddings + локальный re‑ranker.
